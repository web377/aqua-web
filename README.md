# Industrias Aqua — tienda en línea

Next.js (App Router) + TypeScript + Tailwind, desplegado en Vercel, con Supabase.

## Requisitos
- Node 24 (ver `.nvmrc`)

## Comandos
```powershell
npm install        # instala dependencias
npm run dev        # servidor local en http://localhost:3000
npm run lint       # revisión de estilo y errores
npm run typecheck  # revisión de tipos
npm test           # pruebas
npm run build      # compilación de producción
```

Las reglas de trabajo están en `AGENTS.md`.
